## Featured Projects

### Keysyntax

A typing game designed specifically for programmers.

Instead of typing normal sentences, users practice with real code, symbols, brackets, and programming syntax.

- Code-based typing practice
- Typing speed and accuracy tracking
- CPU battles
- Online battles

[Visit Keysyntax](https://keysyntax.com)

### Oto-Ate!

A music guessing game where players identify songs from short audio sections.

Built with React, TypeScript, Firebase, and Vercel.

[Open Web App](https://oto-ate-ebon.vercel.app/)  
[Native Version](https://github.com/HiroyukiGPU/oto-ate)

### RemoteMac

An experiment that turns a smartphone into a remote trackpad for a Mac.

Built using Swift and native Apple technologies.

[GitHub](https://github.com/HiroyukiGPU/RemoteMac)

### WattFlow

A macOS project that visualizes which processes are consuming battery power.

The goal is to make system resource usage easier to understand through visual feedback.

[GitHub](https://github.com/HiroyukiGPU/wattflow)

### Database Design Documentation Tool

A tool for documenting database structures like a document rather than managing them only as diagrams.

It helps developers organize tables, columns, relationships, and project documentation.

[Open App](https://db-docs-canvas.vercel.app/)

### Secure Chat CLI

A chat application designed to work directly inside the terminal.

[GitHub](https://github.com/HiroyukiGPU/secure-chat-cli)

### Tech News Morning

A personal news service that automatically delivers technology news based on the user's interests.

[Open App](https://news-chi-nine-53.vercel.app/)

### RoadLaw Now

A small React app that uses your current location to show information about driving laws in the country you're in.

[Open App](https://hiroyukigpu.github.io/roadlaw-now/)
